# Runtime

> Memory is the product. The runtime makes it usable from anywhere.

| Page | Job |
|------|-----|
| [Runtime](/vant/runtime/runtime) | Programmatic API: init, learn, remember, agents, sync |
| [MCP](/vant/runtime/mcp) | JSON-RPC tools for any MCP client, auto-wired from modules |
| [Server](/vant/runtime/server) | Headless REST mode and the health endpoint |

## Picking a channel

Driving an agent harness that speaks MCP: [MCP](/vant/runtime/mcp). Writing Node code
against Vant: the [runtime API](/vant/runtime/runtime). Everything else, including CI and
containers: the [CLI](/vant/reference/cli) and the [headless server](/vant/runtime/server).
