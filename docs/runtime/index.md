# Runtime

> Memory is the product. The runtime makes it usable from anywhere.

| Page | Job |
|------|-----|
| [Runtime](runtime) | Programmatic API: init, learn, remember, agents, sync |
| [MCP](mcp) | JSON-RPC tools for any MCP client, auto-wired from modules |
| [Server](server) | Headless REST mode and the health endpoint |

## Picking a channel

Driving an agent harness that speaks MCP: [MCP](mcp). Writing Node code
against Vant: the [runtime API](runtime). Everything else, including CI and
containers: the [CLI](../reference/cli) and the [headless server](server).
