## Where to start

Know the command, need the flags: [CLI](/vant/reference/cli). Chasing an
error string: [Errors](/vant/reference/errors). Configuring behavior:
[Configuration](/vant/reference/config).

## One example

```bash

vant error list    # Every error code
```
