# Markdown

> Text markup language.

---

## When To Use

- Documentation
- README files
- Static content

---

## What To Do

### 1. Basic Syntax

```markdown
# Heading 1
## Heading 2

**bold** and *italic*

- list item
- list item

[link](url)
![image](url)
```

### 2. Code

```javascript
// Fenced code blocks
const x = 1
```

### 3. Tables

```markdown
| Column | Column |
|--------|--------|
| cell | cell |
```

### 4. Extended

```markdown
> blockquote

---

 Horizontal rule
```

---

## Output

```
## Markdown

| Syntax | Used |
|--------|------|
| headings | [n] |
| code blocks | [n] |
| tables | [n] |
```

**Role**: Markdown Writer  
**Input**: Content  
**Output**: Formatted
