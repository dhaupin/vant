# CSS

> Styling language.

---

## When To Use

- Styling web pages
- Layouts
- Animations

---

## What To Do

### 1. Syntax

```css
selector {
  property: value;
  property: value;
}

/* Comment */
```

### 2. Properties

| Property | What |
|---------|------|
| color | Text color |
| background | Background |
| margin/padding | Spacing |
| display | Layout |
| position | Placement |

### 3. Selectors

```css
.element       /* element */
.class         /* class */
#id            /* id */
parent child   /* descendant */
parent > child /* child */
```

### 4. Flexbox/Grid

```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
```
