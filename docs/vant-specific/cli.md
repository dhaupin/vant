# CLI

Command reference. All commands.

---

## Core Commands

```bash
vant start       # Boot brain
vant health     # Diagnostics
vant onboard    # Browse brain
vant sync       # GitHub sync
vant test       # Run tests
```

---

## Islands

```bash
vant islands list      # Show available
vant islands load X    # Load one
```

---

## Resolution

```bash
vant resolution --add "X"
vant resolution query "X"
```

---

## Config

```bash
vant config get X
vant config set X Y
```

---

## MCP

```bash
vant mcp    # Start MCP server
```
