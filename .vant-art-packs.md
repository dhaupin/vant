# Art packs — reserved style names & promotion note (#195)

> **What this is:** the operator note for the horcrux starter packs. The
> engine is `lib/art-packs.js`; the door surface is
> `canvas.renderStoneArt(opts)` / `canvas.artPacks()` and
> `vant horcrux create|refresh --art <pack>`.

## Reserved style names

Five `style` values are now RESERVED in the horcrux-template style position and can never mean a legacy render again:

| Pack    | Meaning      | Visual motif                                     |
|---------|--------------|--------------------------------------------------|
| `backup`| AMBER-DEEP   | archive fossilization — phyllotaxis sunflower (220 pts, golden angle), amber radial field, gold motes |
| `stone` | INDIGO-VAULT | sealed lattice — denser colony, violet accent ring |
| `comms` | SIGNAL-TEAL  | radiating rings — colony + 6 decaying signal rings |
| `airgap`| MASK-MONO    | interference only — mono field + two interfering grids, one seed-rotated |
| `crest` | CREST-DUSK   | the OS wave — dusk→amber sky, seed-jittered stars, a rising sine crest with gold foam, a gold horizon line, the soul-colony riding the trough, one violet vault star above |

Default carrier art is `backup` (AMBER-DEEP), used by the `transform.toHorcrux` fallback whenever no `models/public/boot/horcrux-template.svg` exists on disk. Pick per-stone with `--art backup|stone|comms|airgap|crest` on `vant horcrux create` / `vant horcrux refresh`.

## Determinism contract

Every render is seeded — fnv1a → mulberry32, no `Math.random`, no `Date.now` — pure SVG string out, no fs/storage/sandbox/event side effects: a crash in art can never take a backup down. Same seed + same style → byte-identical stone; distinct seeds → distinct art (the seed reaches the geometry via colony jitter, pinned by `test/art-packs.test.js`).

### Seed source

The CLI seeds from the **active brain name** (per-brain distinct art at zero config). Known trade-off (the issue's future-work slot): the seed is the brain NAME at create time — a rename changes the look on a refreshed stone. Durable seed = brain identity id is the documented follow-up, as is PNG/LSB-path parity.

## Legacy styles keep their bytes

`minimal`, `spiral`, and the legacy default style render their exact historical SVG bytes (byte-pinned in `test/art-packs.test.js`); an unknown/misspelled style still falls back to the legacy default render — only reserved names reroute to the engine.
