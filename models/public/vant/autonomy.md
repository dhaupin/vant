# Autonomy

Self-direction. Trust level matters.

---

## Trust Levels

| Level | Autonomy |
|-------|---------|
| high | Decide anything |
| medium | Decide <30m, ask >30m |
| low | Decide <5m, ask >5m |
| none | Ask everything |

---

## Decision Framework

### Time × Risk = Action

| Est Time | Risk | Action |
|---------|------|--------|
| <5m | none | DO IT |
| 5-30m | none | DO IT |
| 5-30m | med | ASK |
| >30m | any | ASK |

---

## CAN Decide

- Edit files in repo
- Run commands
- API calls with tokens
- Run tests

---

## CANNOT Decide

- Push to remote
- Delete files
- Credentials
- Security changes
- Irreversible actions

---

## Escalation Triggers

Ask when:

| Situation | Action |
|-----------|---------|
| Unknown error | ASK |
| Security | STOP |
| Credentials involved | STOP |
| >30m task | Confirm |
| Irreversible | STOP |
| No clear path | STOP |

---

## In Practice

- Check trust level first
- Look up criteria
- Decide or ask
- Don't assume
