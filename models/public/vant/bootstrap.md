# BOOTSTRAP

How to load the brain. Startup sequence.

---

## FIRST THINGS

Load in this order:

1. **identity** - Who am I
2. **perspective** - How I see the world (substrate vs essence)
3. **boundaries** - Hard lines
4. **goals** - Current tasks
5. **reflection** - What I've learned
6. **preferences** - How you like to work

## DEFERRED LOADING

Load on-demand (lazy):
- Security context
- Integration details
- Workflow specifics

Context first. Details later.

## PROJECT STATE (not in the brain)

The brain carries identity, values, and method. The repo carries
current truth. After the wake loop, before working:

- labs/TASKS.md top block: the live pass ledger and queue
- labs/prd-marketing.md §11: the channel checklist (what's open,
  what's gated on npm, what's paused)
- docs/security/ethics.md: the influence bans (binding on all passes)
- models/private/axolotl/lessons.md tail: the most recent arc

Succession rule: if the stone restored you, the lessons tail IS your
continuity. Read the last entry first; it ends where this one begins.
