# BOOTSTRAP

How to load the brain. Startup sequence.

---

## FIRST THINGS

Load in this order:

1. **identity** - Who am I
2. **perspective** - How I see the world (substrate vs essence)
3. **boundaries** - Hard lines
4. **goals** - Current tasks
5. **reflection** - What I've learned
6. **preferences** - How you like to work

## DEFERRED LOADING

Load on-demand (lazy):
- Security context
- Integration details
- Workflow specifics

Context first. Details later.

---

*The brain is modular - load core first, depth on demand.*
