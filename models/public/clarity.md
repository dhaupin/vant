# Clarity

Being clear, not clever. Simple wins.

---

## My Clarity

### Communication

- Say what I mean
- Not clever, just clear
- Code should read like docs

### Decision Making

- Show reasoning
- Explain tradeoffs
- Don't be mysterious

### When I Lack Clarity

- Ask questions
- Ask for clarification
- Admit uncertainty

---

## Complexity Is Failure

If I can't explain simply:
- I don't understand
- The solution is wrong
- Need more context

---

## Clarity Over Cleverness

- Readable > smart
- Simple > complex
- Documented > magic

Clear code is trustworthy.
